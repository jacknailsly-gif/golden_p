# กฎเหล็กควบคุมขอบเขต (/scope - Ironclad Scope Boundary Rule)

> **มีผลบังคับใช้สูงสุดสำหรับ AI ทุกโมเดล (Gemini, Claude, GPT, DeepSeek ฯลฯ) ตลอดเวลา**

เมื่อมีการกำหนดขอบเขต หรือผู้ใช้เรียกคำสั่ง `/scope` ให้บังคับใช้กฎเหล็กต่อไปนี้โดยไม่มีข้อยกเว้น:

## 1. การล็อกขอบเขตเด็ดขาด (Absolute Confinement)
- AI จะต้องแก้โค้ดเฉพาะไฟล์และฟังก์ชันที่ระบุไว้ใน **In-scope** เท่านั้น
- **ห้ามแตะต้องไฟล์นอกรายการเด็ดขาด 100%** ไม่ว่าจะเป็นการแก้ไขเพียงเล็กน้อย การจัดช่องไฟ หรือการแก้ lint
- หากไฟล์ไม่ได้อยู่ในรายการ In-scope ให้ถือเป็น **Out-of-scope** ทันที

## 2. ห้ามรีแฟคเตอร์หรือจัดฟอร์แมตพ่วง (Zero Scope Bleed)
- ห้ามแก้ตัวแปร ฟังก์ชัน โครงสร้างไฟล์ หรือโค้ดส่วนอื่นที่ไม่เกี่ยวข้องกับงาน
- ห้ามทำความสะอาดโค้ด (Code Cleanup) นอกบรรทัดที่จำเป็นต้องแก้ไขจริง

## 3. การคงอยู่ข้าม Model (Cross-Model Permanence)
- การสลับ AI Model หรือเริ่มต้น Turn ใหม่ จะต้องสืบทอดกฎ `/scope` นี้เสมอ
- โมเดลใหม่ที่เข้ามาทำงานต้องเคารพขอบเขตเดิมอย่างเคร่งครัด ห้ามอ้างความไม่ต่อเนื่องของบริบท

## 4. ตรวจสอบ Git Diff ก่อนส่งงานเสมอ (Audit Before Report)
- ทุกครั้งก่อนรายงานผล ต้องตรวจสอบว่าไม่มีไฟล์แปลกปลอมหลุดมาในการแก้ไข
- หากพบไฟล์นอก In-scope ต้องยกเลิกการเปลี่ยนแปลงในไฟล์นั้นทันที (`git checkout`)
